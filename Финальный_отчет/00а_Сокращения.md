Таблица 0.2 – Сокращения и термины

| Сокращение | Расшифровка |
|---|---|
| TAM | весь рынок: общий объем рынка продукта в границах проекта |
| SAM | доступный рынок: часть рынка, которую можно обслужить продуктом в выбранных территориях и сегментах |
| SOM | достижимая часть рынка: доля, которую проект может занять в рассматриваемый период |
| CR3, CR5 | доли трех и пяти крупнейших игроков в релевантном трафике |
| HHI | индекс Херфиндаля - Хиршмана: сумма квадратов долей игроков в процентах, мера концентрации рынка |
| CPC | стоимость клика в рекламе |
| ARPPU | средняя выручка на одного платящего пользователя |
| GT | Google Trends: относительный индекс интереса к запросам, от 0 до 100 внутри пакета |
| YW | Яндекс Вордстат: число запросов к поисковой системе Яндекс |
| EUC | пользовательские вычисления конечного пользователя, в том числе таблицы Excel как источник операционного риска |
| MVP | минимально жизнеспособный продукт |
| ЦП | ценностное предложение |
| Канвас | модель бизнес-модели из девяти блоков (Business Model Canvas) |
| Кано | модель классификации функций продукта по влиянию на удовлетворенность |
| Левитт | модель трех уровней продукта: ядро, реальный и расширенный продукт |
| ПЗ1, ПЗ4 | практические занятия по управлению проектом, из которых взяты факты проекта (тарифы, бюджет, сроки) |
| НБРБ | Национальный банк Республики Беларусь, источник курсов валют |
| модельные данные | данные, полученные расчетной моделью с названными допущениями, а не измеренные; везде названы модельными |
| релевантный трафик | часть трафика сайта, относящаяся к рынку проекта: целевые страны, нужное содержание, коэффициент качества |

Перечень охватывает сокращения всех работ; расшифровки при первом употреблении повторены и в тексте соответствующей работы.
