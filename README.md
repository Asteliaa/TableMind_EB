# TableMind_EB

Лабораторные работы по дисциплине «Электронный бизнес» (БГУИР), выполненные на примере проекта **TableMind** - облачного AI-сервиса проверки Excel-моделей (веб-аудит и надстройка для Excel; принцип «LLM предлагает, движок доказывает»).

Выполнила: Р. В. Земляник, гр. 60131. Остаток работ: `ОСТАЛОСЬ_СДЕЛАТЬ.md`.

## Состав

| Папка | Работа | Статус |
|---|---|---|
| `ЛР1_Спрос_и_границы_рынка` | ЛР1. Спрос, семантическое ядро, Google Trends, Вордстат, тренд и сезонность, границы рынка | выполнена (65 с.) |
| `ЛР2-3_Объем_рынка` | ЛР2-3. Оценка объема рынка (TAM/SAM/SOM): 7 книг Excel, снимок Similarweb, воронка по тарифам, платежеспособность | выполнена (36 с.), данные дополнены |
| `ЛР4_Пять_сил_Портера` | ЛР4. Пять сил Портера, конкуренция и барьеры входа: 2 книги Excel, 21 игрок, карточки конкурентов, стратегия входа | выполнена (29 с.) |
| `ЛР5_Анализ_конкурентов` | ЛР5. Уровни конкуренции, цифровой товар (Левитт, Кано), бизнес-модели конкурентов: 3 книги Excel, 7 конкурентов, стандарт рынка | выполнена (42 с.) |
| `ЛР6_ЦП_Канвас_сценарии_релизы` | ЛР6. Ценностное предложение, Канвас, сценарии, экраны, релизы: 5 книг Excel, 155 проверок, схемы экранов, макеты Figma | выполнена (46 с.) |
| `ЛР7_Итоговый_отчет` | ЛР7. Итоговый отчет по бизнес-анализу и краткое резюме | выполнена (24 с.), решение: полный старт |

| `_tools` | Сборка Word по СТП БГУИР 01-2024 и проверки | настроено |

План работ: [ПЛАН_ВЫПОЛНЕНИЯ.md](ПЛАН_ВЫПОЛНЕНИЯ.md).

## Раскладка внутри каждой работы

`Excel/` - заполненные шаблоны, `Python/` - расчеты и графики, `Рисунки/`, `Скриншоты/`, `Материалы_собранные/` - выгрузки и журналы, `ПЛАН.md`, `ОТЧЕТ.md` (источник отчета), `ОТЧЕТ_<ЛР>_TableMind.docx` (итоговый Word).

Оригиналы методик и Excel-шаблонов преподавателя в репозиторий не включаются.

## Сборка отчетов

```bash
python _tools/build_lab_docx.py ЛР1      # один отчет (нужны pandoc и python-docx)
python _tools/build_lab_docx.py          # все отчеты и финальный
python _tools/verify_labs.py             # проверки структуры, метаданных, ошибок Excel
```

## Ветки

`main` - принятые работы; изменения вносятся через pull request. Ветки `lab1`...`lab7` и `final` - рабочие ветки по работам (ЛР1-ЛР7, финальный отчет).
