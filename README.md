# TableMind_EB

Лабораторные работы по дисциплине «Электронный бизнес» (БГУИР), выполненные на примере проекта **TableMind** - облачного AI-сервиса проверки Excel-моделей (веб-аудит и надстройка для Excel; принцип «LLM предлагает, движок доказывает»).

Выполнила: Р. В. Земляник, гр. 60131.

## Состав

| Папка | Работа | Статус |
|---|---|---|
| `ЛР1_Спрос_и_границы_рынка` | ЛР1. Спрос, семантическое ядро, Google Trends, Вордстат, тренд и сезонность, границы рынка | выполнена, ожидает доснять данные (ИНСТРУКЦИЯ_ДЛЯ_МЕНЯ.md) |
| `ЛР2-3_Объем_рынка` | ЛР2-3. Оценка объема рынка (TAM/SAM/SOM): 7 книг Excel, снимок Similarweb, воронка по тарифам, платежеспособность | выполнена (ветка `lab2-3`) |
| `ЛР4_Пять_сил_Портера` | ЛР4. Пять сил Портера, конкуренция и барьеры входа | не начата |
| `ЛР5_Анализ_конкурентов` | ЛР5. Уровни конкуренции, цифровой товар (Левитт, Кано), бизнес-модели конкурентов | не начата |
| `ЛР6_ЦП_Канвас_сценарии_релизы` | ЛР6. Ценностное предложение, Канвас, сценарии, экраны, релизы | не начата |
| `ЛР7_Итоговый_отчет` | ЛР7. Итоговый отчет по бизнес-анализу и краткое резюме | не начата |
| `Финальный_отчет` | Сводный отчет по ЛР1-7 | не начат |
| `00_Общее` | Факты проекта, журнал допущений, журнал решений | ведется |
| `_tools` | Сборка Word по СТП БГУИР 01-2024 и проверки | настроено |

План работ: [ПЛАН_ВЫПОЛНЕНИЯ.md](ПЛАН_ВЫПОЛНЕНИЯ.md).

## Раскладка внутри каждой работы

`Excel/` - заполненные шаблоны, `Python/` - расчеты и графики, `Рисунки/`, `Скриншоты/`, `Материалы_собранные/` - выгрузки и журналы, `ПЛАН.md`, `ОТЧЕТ.md` (источник отчета), `ОТЧЕТ_<ЛР>_TableMind.docx` (итоговый Word).

Оригиналы методик и Excel-шаблонов преподавателя в репозиторий не включаются.

## Сборка отчетов

```bash
python _tools/build_lab_docx.py ЛР1      # один отчет (нужны pandoc и python-docx)
python _tools/build_lab_docx.py          # все отчеты и финальный
python _tools/verify_labs.py             # проверки структуры, метаданных, ошибок Excel
```

## Ветки

`main` - принятые работы; работа над каждой ЛР ведется в ветке `lab1`, `lab2-3`, `lab4`, `lab5`, `lab6`, `lab7`, `final` и вливается в `main` через pull request.
