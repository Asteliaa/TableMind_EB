# Факты проекта TableMind (единый источник чисел)

Источник: ПЗ1 «Концепция проекта», ПЗ4 «WBS и календарно-сетевое планирование», реестр рисков (курс «Управление проектами», гр. 60131, Земляник Р.В.). Любое число в отчетах по ЭБ сверяется с этим файлом; при расхождении правится либо отчет, либо этот файл с записью в журнале решений.

| Параметр | Значение | Источник |
|---|---|---|
| Продукт | облачный AI-сервис проверки таблиц Excel: веб-аудит финансовых моделей и надстройка Excel | ПЗ1, 1.1 |
| Принцип | «LLM предлагает, движок доказывает»: числа попадают в документ только из вычисления, не из генерации модели | ПЗ1, 1.1 |
| Клиенты | финансовые аналитики и FP&A малого и среднего бизнеса, консультанты и инвестаналитики, бухгалтеры и аутсорс-фирмы, основатели и операционные менеджеры | ПЗ1, 1.1 |
| Модель дохода | freemium SaaS: Free, разовый аудит 9 EUR, Pro 19 EUR в месяц, Team 29 EUR за место (со следующего релиза) | ПЗ1 фиксирует бесплатный и платные тарифы, Stripe, тарифы 01.04-30.04.2027 и командный тариф в следующем релизе; суммы 9/19/29 EUR приняты в ЭБ (ЛР2-3, ПЗ1 v4 цен не содержит) |
| Проблема | ошибки есть в 86-94 % реальных таблиц; AI-надстройки лидеров рынка сами требуют проверки | ПЗ1, 1.1 |
| Рынок (оценка ПЗ1) | табличное ПО около 11 млрд USD, рост 6-8 % в год, около двух третей спроса в Северной Америке и Европе | ПЗ1, 1.2 |
| Конкуренты (ПЗ1) | PerfectXL, Shortcut, Microsoft 365 Copilot, ChatGPT for Excel, Claude for Excel | ПЗ1, 1.2, 4 |
| Территория (решение Р-1) | основная: англоязычные страны и ЕС; контрольная: Беларусь и русскоязычный сегмент | журнал решений |
| Каналы | веб-приложение, надстройка в Microsoft AppSource, партнеры (бухгалтерские и консалтинговые фирмы, преподаватели Excel), Product Hunt | ПЗ1, ПЗ4 |
| Срок проекта | 01.10.2026 - 30.09.2027 (12 месяцев) | ПЗ1 |
| Вехи | ТЗ 31.10.2026; MVP веб-аудита 31.03.2027; открытая бета с оплатой 01.06.2027; бета v1 с надстройкой июль 2027; релиз сентябрь 2027 | ПЗ1 |

| Цели | не менее 300 регистраций и 50 платящих пользователей к 30.09.2027 | ПЗ1, 1.3 |
| Качество | precision критичных находок не ниже 90 %, recall не ниже 80 %, аудит файла до 100 тыс. ячеек быстрее 60 с | ПЗ1, 1.4 |

В. Земляник; руководитель И. В. Кашникова; Минск 2026. Титульные данные взяты из отчетов ПЗ1 и ПЗ4 по «Управлению проектами» (папка project-management-tablemind) по указанию студентки 03.10.2026.
