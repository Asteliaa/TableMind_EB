# Факты проекта TableMind (единый источник чисел)

Источник: ПЗ1 «Концепция проекта», ПЗ4 «WBS и календарно-сетевое планирование», реестр рисков (курс «Управление проектами», гр. 60121, Земляник Р.В.). Любое число в отчетах по ЭБ сверяется с этим файлом; при расхождении правится либо отчет, либо этот файл с записью в журнале решений.
