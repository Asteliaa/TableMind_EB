# Модельные данные опроса

**Это не результат опроса реальных респондентов.** Респондентов нет (решение Р-8): данные сгенерированы скриптом `survey_model.py` по заданным параметрам (seed 20261003, 30 условных респондентов в 4 сегментах).

Состав: `respondents.csv` (сегмент, часы с таблицами, ошибки за год, инструмент, четыре цены Ван Вестендорпа для Pro, максимум за разовый аудит, готовность 1-5, выбор тарифа), `kano_responses.csv` (функциональные и дисфункциональные ответы по 16 функциям ЛР5), `summary.json` (сводка: точки PMC/OPP/IPP/PME, доли, категории Кано, Better и Worse).

Параметры генератора заданы аналитиком (ценовой коридор книги 3 ЛР2-3, категории Кано ЛР5, доля согласия с категорией аналитика 58 %), поэтому данные проверяют механику расчета и согласованность допущений, но не доказывают спрос. Использование: приложения Г отчетов ЛР2-3 и ЛР5.

Запуск: `python 00_Общее/Опрос_модельный/survey_model.py`, затем пересборка отчетов ЛР2-3 и ЛР5.
