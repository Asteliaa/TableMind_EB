# Журнал допущений

Допущение - значение, которого нет в открытых данных и которое принято экспертно или смоделировано. Каждое допущение получает номер, значение, обоснование, влияние на результат и способ проверки. Допущения ссылаются на работу, где они возникли.

| № | Работа | Параметр | Значение | Обоснование | Влияние | Как проверить |
|---|---|---|---|---|---|---|
| Д-01 | - | - | - | - | - | - |

Пометка в отчетах для данных, которых нет в открытом доступе: «ДОСНЯТЬ: что, где, как». Модельные (сгенерированные) данные опроса помечаются словами «модельные данные» в тексте, подписях таблиц и приложении.
