# Краткое резюме проекта TableMind

Резюме для владельца проекта и инвестора на основе бизнес-анализа ЛР1-ЛР7. Дата: 03.10.2026. Подготовила Р. В. Земляник. Числа сверены с ПЗ1 и ПЗ4; курс НБРБ: 1 EUR = 3,3860 BYN.

## 1. Паспорт проекта и управленческое решение

| Параметр | Содержание |
|---|---|
| Название проекта | TableMind |
| Инициатор / владелец | Р. В. Земляник |
| Суть проекта в одном предложении | Проект создает облачный сервис проверки Excel-моделей для финансовых аналитиков, консультантов, бухгалтеров и малого бизнеса, чтобы находить скрытые ошибки в формулах до передачи файла за счет движка, который доказывает каждую находку вычислением |
| Запрашиваемое решение | Рекомендуется полный старт проекта по плану ПЗ1 (MVP веб-аудита 31.03.2027, открытая бета с оплатой 01.06.2027, релиз 09.2027) с контрольными метриками |
| Граница первого старта | англоязычные страны и ЕС; финансовые аналитики и консультанты; поиск по проблемным запросам, AppSource, партнерские фирмы; самообслуживание с бесплатным входом |

## 2. Идея, рыночная возможность и достаточность рынка

| Блок вывода | Краткая запись |
|---|---|
| Идея | Ошибки есть в 86-94 % реальных таблиц, результат AI-помощников сам требует проверки; существующие решения не доказывают находки |
| Спрос | Поисковый интерес подтвержден частично: проблемные и AI-запросы массовые (кластеры 25 тыс. и 21 тыс. запросов в месяц в русскоязычном сегменте), прямой запрос на аудит мал; динамика Google Trends растет, Вордстата снижается |
| Границы рынка | Онлайн-проверка Excel-моделей; США, Великобритания, Канада, Австралия, Ирландия и ЕС-27; контрольный русскоязычный сегмент |
| Размер рынка | SAM около 35 млн EUR в год (диапазон 15-69 млн); SOM первого года 7-206 тыс. EUR, базовый около 46 тыс. EUR |
| Барьеры входа и выхода | Входа: средние (индекс 3,15 из 5), критичны заменители; выхода: низкие, цифровой проект без обязательств перед клиентами |

Итог этапа: основание для старта есть - проблема значимая, рынок достаточен для проверки, барьеры управляемы; спрос требует подтверждения на MVP.

## 3. Конкурентная среда и незакрытая проблема

| Вывод | Формулировка |
|---|---|
| Уровень конкуренции | Близкие альтернативные: PerfectXL, Microsoft Copilot, Shortcut, Arixcel. Косвенные и заменители: Operis, DataSnipper, Datarails, Numerous.ai, Rows, Formula Bot. Прямых конкурентов в строгом смысле нет |
| Рыночный стандарт | Надстройка Excel (7 из 7); обязательные признаки - поиск ошибок, безопасность и GDPR, пробный доступ (по 3 из 7) |
| Конкурентные преимущества | Доказательство каждой находки движком, прозрачная цена, бесплатный старт, публичные отзывы (у прямых конкурентов 0-19) |
| Главная проблема клиента | Клиент не может уверенно передать модель заказчику, не рискуя скрытой ошибкой, и не может подтвердить результат AI-помощника |

## 8. Итоговая формулировка решения

Рекомендуется полный старт (решение владельца проекта 03.10.2026): ценностное предложение перспективно, а проверка конверсий, цены и канала привлечения идет в ходе реализации и управляется как риск. Следующий шаг - запуск MVP веб-аудита 31.03.2027 и измерение метрик.

## 9. Краткий вывод для резюме

Проект TableMind целесообразно рассматривать как облачный сервис независимой проверки Excel-моделей для финансовых специалистов англоязычных стран и ЕС. Его ценность основана на решении массовой проблемы скрытых ошибок и на доказательстве каждой находки. Рынок достаточен для проверки гипотезы (SAM около 35 млн EUR в год), конкурентный пробел найден, первый релиз реалистичен. Условия продолжения: precision не ниже 90 %, конверсия регистрация - платящий не ниже 5 %, дополнительные каналы для достижения 50 платящих.
